# Glossary

Terms introduced across the modules, alphabetically. This grows as
module content is expanded — see `CONTRIBUTING.md` if a term you
learned here is missing.

## A

- **AppArmor** — a Linux security module restricting programs'
  capabilities via per-application profiles. *(Module 16)*

## B

- **Bootloader (GRUB)** — the program that loads the Linux kernel into
  memory during startup. *(Module 03)*

## C

- **Cron** — a time-based job scheduler for running commands on a
  schedule. *(Module 06)*

## D

- **DKIM/SPF** — email authentication standards used to reduce
  spoofing and spam. *(Module 13)*

## F

- **FHS (Filesystem Hierarchy Standard)** — the standard defining
  Linux's directory structure and purpose of each top-level directory.
  *(Module 05)*

## I

- **init system (systemd)** — the first process started by the kernel,
  responsible for starting all other services. *(Module 03)*

## L

- **LDAP (Lightweight Directory Access Protocol)** — a protocol for
  accessing and managing directory (user/group) information, the
  modern replacement for NIS. *(Module 15)*
- **LVM (Logical Volume Manager)** — a Linux subsystem for flexible
  disk partition management. *(Module 05)*

## N

- **NFS (Network File System)** — a protocol allowing a filesystem to
  be shared and mounted over a network. *(Module 14)*
- **NIS (Network Information System)** — a legacy centralized
  account-management protocol, insecure by modern standards.
  *(Module 15)*

## P

- **PAM (Pluggable Authentication Modules)** — a framework allowing
  flexible configuration of authentication methods on Linux.
  *(Module 02)*

## S

- **SELinux** — a Linux security module enforcing mandatory access
  control policies. *(Module 16)*
- **Signal (process)** — a message sent to a process to instruct it to
  do something (terminate, reload config, etc). *(Module 06)*
- **SSH (Secure Shell)** — an encrypted protocol for remote
  administration of Linux systems. *(Module 08)*
- **systemd target** — systemd's equivalent of a traditional runlevel,
  a defined system state. *(Module 03)*
