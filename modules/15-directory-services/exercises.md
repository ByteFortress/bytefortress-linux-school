# Module 15 — Extra Exercises

## Exercise 1 — LDIF from scratch

Write an LDIF file defining three users and one group with two of those users as members, and load it in one `ldapadd` operation.

## Exercise 2 — Search filters

Practice `ldapsearch` with different filter syntax: find a user by uid, find all users in a specific group, find users whose uidNumber is above a certain value.

## Exercise 3 — NIS vs LDAP writeup

Write a short comparison (in your own words, no need for external research beyond this module) of why NIS is no longer recommended and what specific LDAP feature addresses each NIS weakness.
