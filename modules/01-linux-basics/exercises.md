# Module 01 — Extra Exercises

## Exercise 1 — Editor speed-run

Time yourself making the same 3-line edit to a file in Vim, then in Nano. Note which felt faster and why — this is purely about building comfort, not proving one editor is better.

## Exercise 2 — Man page scavenger hunt

Using only `man` pages (no web search), find: the flag to make `rm` ask for confirmation, the flag to make `cp` copy directories recursively, and the flag to make `grep` case-insensitive.

## Exercise 3 — Distro detective

If you have access to more than one Linux system (or spin up a second VM with a different distro), compare `/etc/os-release`, the default package manager, and the default shell across both.
