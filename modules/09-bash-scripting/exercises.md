# Module 09 — Extra Exercises

## Exercise 1 — Log rotation script

Write a script that finds log files older than N days in a directory and compresses them with gzip, taking N as a command-line argument with a sensible default.

## Exercise 2 — User creation automation

Write a script (using module 02's `useradd`/`usermod` commands) that reads a list of usernames from a text file, one per line, and creates an account for each with a home directory.

## Exercise 3 — Health check script

Write a script that checks disk usage, memory usage, and whether a specific service is running, printing a simple OK/WARNING status for each.

## Exercise 4 — Capstone project

Once the three exercises above feel comfortable, module 04's
`exercises.md` has a substantial multi-script bash project (building
a small package manager from scratch) that pulls together everything
from this module — functions, argument parsing, file I/O, and real
error handling — into one real piece of software.
