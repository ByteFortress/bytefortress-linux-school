## Suggested convention for your own write-ups

If you're keeping personal notes/screenshots per module (recommended
— several exercises ask you to write things up in a `NOTES.md`), a
simple naming pattern makes it easy to find things later and to
archive or share a module's work as one file:

```bash
mkdir module-04
cd module-04    # put NOTES.md, screenshots, etc. here
cd ..
tar czf module-04.tar.gz module-04/
```

One archive per module, named consistently — trivial to automate
later if you end up doing this across many modules.
