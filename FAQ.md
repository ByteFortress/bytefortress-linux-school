# FAQ

## Do I need to finish `bytefortress-foundations-school` first?

Strongly recommended. This repo assumes the shell comfort, basic
permissions knowledge, and VM lab setup covered there. If you're
already comfortable with those from elsewhere, you can skip straight
here.

## Why does this repo mention an old course of yours?

This curriculum is being rebuilt from an older course I taught myself
(*CS101: Linux System Administration*, originally ~2020). The module
structure and lab philosophy come from real teaching experience — the
content itself is being refreshed and expanded here as an open
project, module by module.

## Some modules feel thinner than others — why?

This repo is actively being expanded. Every module has a working
structure, a real hands-on lab, and a real external resource, but
some are still getting fuller original explanations added. Contributions
welcome — see `CONTRIBUTING.md`.

## What Linux distro should I use?

Ubuntu Server 22.04 LTS is assumed throughout, matching
`bytefortress-foundations-school`'s module 08 setup. Commands will
differ slightly on Red Hat/Fedora-based or Arch-based systems — the
concepts transfer either way.

## Do I need multiple VMs?

Some modules (07, 08, 11-15) are much more useful with at least two
VMs so you can practice client/server setups (e.g. a DNS server and a
client querying it). One VM is enough to start; add a second when a
module's lab calls for it.

## How does this differ from just getting a Linux+ or LPIC cert?

This repo covers a lot of the same ground conceptually but isn't exam
prep and doesn't follow an official exam blueprint. It should make
studying for Linux+/LPIC easier afterward, similar to how
`bytefortress-foundations-school` relates to Security+.

## I found an error / broken link — what do I do?

Open an issue or submit a PR. See `CONTRIBUTING.md`.
