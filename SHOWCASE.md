# Showcase

A place to share what you built while working through this repo — a
running mail server, a hardened box that passed a CIS benchmark scan,
a backup system you actually tested a restore on, anything.

## How to add yours

Open a PR adding an entry below:

```markdown
### <Your name or handle> — <date>

Brief description of what you built and which modules it came from.
A screenshot, diagram, or config snippet is welcome (host large files
in your own repo/gist and link here).

Link to your own write-up, if you're comfortable sharing.
```

Keep entries free of real credentials, real public IPs, or anything
identifying a system outside your own lab.
